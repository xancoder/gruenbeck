# gruenbeck webserver documentation

- `Gruenbeck_Webserver_Dokumentation.pdf`: the [documentation of the gruenbeck webserver](https://www.loxwiki.eu/download/attachments/37618129/Gruenbeck_Webserver_Dokumentation.pdf?version=1&modificationDate=1546461261000&api=v2) or [alternative](https://www.loxwiki.eu/download/attachments/18219874/Gruenbeck_Webserver_Dokumentation.pdf?version=1&modificationDate=1497260914000&api=v2), as published
- `Gruenbeck_Webserver_Dokumentation.csv`: the parameter list of that documentation, converted manually into a comma-separated-values file. It is documentation only: the data collector does not read it (it asks for the fixed parameters `D_C_4_2` and `D_Y_2_1` ... `D_Y_2_14`, see `gruenbeck.device`), and the configuration has no key for it
